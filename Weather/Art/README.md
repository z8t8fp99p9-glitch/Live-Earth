# Weather Live Art

This folder is the exclusive home for LIVE // EARTH Weather Live Art production material.

- `LIVE-ART-PRODUCTION-GUIDE.md` is the approved, binding production standard.
- `References/approved-style-reference-001.jpg` is the approved visual benchmark. It is a reference only, not a display artwork.
- Future approved display images and their catalogue records belong under this folder only.

The current package saves the guide and its visual reference. It does not change the Weather renderer, remove existing procedural studies, or make new images appear in the app. Those are separate implementation tasks requiring source inspection and testing.
