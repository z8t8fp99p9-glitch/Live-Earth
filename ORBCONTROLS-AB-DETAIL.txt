orb-controls-v4.js — A/B GUARD

The included complete file differs from the current main copy only by wrapping these four existing event-listener registrations in a feature-flag guard:
- orientationchange -> settleAfterRotation
- window resize -> syncViewport
- visualViewport resize -> syncViewport
- pageshow -> settleAfterRotation

The initial syncViewport() call remains active. All other Orb state, UI, Location-OFF handling, Stacks, panel behavior, and readiness signaling are preserved.

The flag is enabled only by ios-standalone-root-flow.js after it confirms iOS/iPadOS Home Screen standalone mode. To end the A/B test later, set window.__LE_DISABLE_LEGACY_VIEWPORT_RECOVERY__ = false in the helper and publish a new version. Do not delete the original recovery implementation.
