# Atmosphere cinematic HUD — Phase 2

- Replaces the large five-tile information card with a compact glass HUD.
- Keeps the central globe visually open by moving the data card into the lower portion of the feature view.
- Shows the verified global temperature range as the headline; the full metadata grid is inside a native expandable disclosure.
- Preserves the NOAA GFS dataset, checksum validation, Universal Grid System, GPU skin, shared Earth layer contract, cleanup and source attribution.
- No Home, Earth Engine, Stacks registry, navigation, database or service-worker changes.
- The displayed range is a global dataset range, not a local/current-location temperature.
