# LIVE // EARTH — Moon Preview Zoom Gestures

## Interaction
- One-finger drag rotates the Moon.
- Two-finger pinch expands/contracts the Moon smoothly.
- Trackpad/mouse wheel zoom is also supported where available.
- Zoom is clamped to a comfortable range so the Moon cannot disappear into the camera or become an edge-to-edge crop.

## Protection
- Gesture zoom is enabled only for the independent Moon inspection preview.
- Shared Moon Engine camera and production interaction remain unchanged.
- Orbital date, phase, synchronous rotation, lunar texture, and public engine API are unchanged.
- No Earth/Sun engine, Feature Orb registration, production view, Global Orb, or service-worker files are changed.

## Test status
- JavaScript syntax validation and package SHA-256/size validation are run for this package.
- Final touch-gesture feel still requires on-device iPhone testing.
