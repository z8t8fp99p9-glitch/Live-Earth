LIVE // EARTH — RECOVERY / ROLLBACK REMINDER

Use the recovery instructions and the matching dated backup in Recovery/ for the exact file being restored.

Do not blanket-restore every file in Recovery/. Do not restore or change workflow YAML as part of an ordinary code rollback unless that exact workflow change is part of the approved rollback.

Before restoring:
1. Identify the failing file and the matching recovery snapshot.
2. Compare the snapshot with the current file and the intended baseline.
3. Restore only the approved file(s).
4. Run the relevant tests and check the resulting diff.

Never delete or reset .publisher-data, browser caches, IndexedDB, localStorage, the installed PWA or saved PDFs as a generic recovery step. Preserve the last-known-good local data.
