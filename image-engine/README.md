# LIVE // EARTH — Global Image Engine Section 9

This is the Global, View-independent image-processing stage. It receives the initial Checker report, prioritises a suitable approved original image, and may consider alternatives only when explicit Checker route and temporary-processing policies permit them.

The Engine creates only Section 9: Image Intelligence, Editorial Enhancement & Final Checker Submission. It returns one exact candidate or `NO IMAGE SELECTED`, along with lineage, source evidence, technical and visual assessment, preparation record and file hash.

## Ownership boundaries

- The Engine owns Section 9 only.
- It does not edit Checker Sections 1–8.
- It does not approve image rights, create Checker decisions, publish assets or write View databases.
- Section 9 is immutable after creation.
- Checker adds Section 10 (Final Image Verification & Approval) and Section 11 (Post-Engine Audit & Final Editorial Decision) as new sections.
- Neither Section 10 nor Section 11 may change Sections 1–9 or add checks to Section 6.
