# Feature View Contract — V88.4 draft

- Main Home remains the five original Orbs.
- Opening a feature via Stacks closes/cleans the previous feature before activating the next and returns the primary scene to Home.
- In feature mode, the bottom dock remains: active feature toggle, Location, Stacks.
- Stacks is a transparent overlay with six vertical feature choices; only the inner list scrolls.
- The rail follows whichever Stacks button is currently visible: Home's five-Orb navigation or the active feature's three-Orb dock.
- Opening/closing Stacks must not activate an unrelated view. Selecting the active feature Orb closes the feature and restores Home navigation.
- Location permission/state is not expanded; feature data layers remain honest placeholders until separately integrated.
